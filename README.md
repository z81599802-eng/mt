# Mubarak Tabarak Monorepo

This repository contains the production-ready Mubarak Tabarak retail platform. It is a multi-app monorepo composed of:

- **apps/customer** – Next.js 14 PWA for shoppers
- **apps/admin** – Next.js 14 dashboard for administrators and cashiers
- **server** – Node.js/Express 5 API powered by Prisma + MySQL
- **docker-compose.yml** – one-command local orchestration
- **nginx.conf** – reverse proxy for customer/admin apps and API

Refer to each subdirectory README for setup and development instructions.
